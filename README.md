# タスク管理アプリ

ビルド不要・サーバー不要のシンプルなカンバン式タスク管理アプリです。`index.html` をブラウザで開くだけで使えます。

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでOK）
2. 「+ タスク追加」からタイトル・詳細・期限・優先度・カテゴリを入力
3. カードをドラッグ&ドロップして「未着手」「進行中」「完了」の間を移動
4. カードをクリックすると編集・削除ができる
5. ヘッダーのセレクトでカテゴリ・優先度による絞り込みが可能

## 機能

- カンバンボード（未着手 / 進行中 / 完了）とドラッグ&ドロップ
- タスクのCRUD（追加・編集・削除）
- 期限・優先度（高・中・低）の管理、期限超過の強調表示
- カテゴリ/タグ分け・フィルタリング
- ブラウザの `localStorage` へ自動保存（ブラウザを閉じても消えない）
- OSのライト/ダークテーマに自動追従、スマホ幅にも対応

## 技術構成

素のHTML / CSS / JavaScriptのみで、フレームワークやビルドツールは使用していません。

| ファイル | 役割 |
|---|---|
| `index.html` | 画面構造 |
| `style.css` | スタイル |
| `app.js` | タスクの状態管理・描画・localStorageへの永続化 |
| `requirements.html` | 要件定義書 |

## データ保存について

タスクは同一ブラウザの `localStorage`（キー: `task-manager-app:tasks`）に保存されます。別のブラウザや別の場所にコピーした `index.html` からは、保存済みのデータを参照できません。
