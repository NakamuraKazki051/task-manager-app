# タスク管理アプリ

ビルド不要・サーバー不要のシンプルなカンバン式タスク管理アプリです。`index.html` をブラウザで開くだけで使えます。

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでOK）
2. 「+ タスク追加」からタイトル・詳細・期限・優先度・カテゴリ・チェックリストを入力
3. カードをドラッグ&ドロップして列間を移動、列内でも自由に並び替え可能
4. カードをクリックすると編集・削除ができる
5. 列見出しをクリックすると列名を変更、末尾の「+ 列を追加」で新しい列を作成
6. ヘッダーのセレクトでカテゴリ・優先度による絞り込みが可能

## 機能

- カンバンボード（列はカスタマイズ可能）とドラッグ&ドロップ、列内の手動並び替え
- タスクのCRUD（追加・編集・削除）とサブタスク/チェックリスト
- 期限・優先度（高・中・低）の管理、期限超過の強調表示
- カテゴリ/タグ分け・フィルタリング
- ブラウザの `localStorage` へ自動保存（ブラウザを閉じても消えない）
- OSのライト/ダークテーマに自動追従、スマホ幅にも対応

## 技術構成

素のHTML / CSS / JavaScriptのみで、フレームワークやビルドツールは使用していません。

| ファイル | 役割 |
|---|---|
| `index.html` | 画面構造 |
| `style.css` | スタイル |
| `app.js` | タスクの状態管理・描画・localStorageへの永続化 |
| `requirements.html` | 要件定義書 |

## データ保存について

タスクは同一ブラウザの `localStorage`（キー: `task-manager-app:tasks`）に、列の構成は同キー配下の `task-manager-app:columns` に保存されます。別のブラウザや別の場所にコピーした `index.html` からは、保存済みのデータを参照できません。
